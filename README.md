# Draftu

Draftu — контент-план для Instagram. Планируй посты, сторис, рилсы и карусели на календаре, прикрепляй фото и видео, организуй хештеги и смотри, как будет выглядеть сетка профиля.

## Возможности

- **Календарь** — недельный и месячный вид, навигация между днями
- **Типы контента** — пост, сторис, рилс, карусель с иконками и статусами (запланировано / готово / опубликовано)
- **Медиа** — прикрепляй фото и видео к записям (сжатие до 1080×1350)
- **Сетка профиля** — предпросмотр Instagram-сетки в формате 4:5
- **Хештеги** — коллекции хештегов для быстрой вставки
- **Метки** — цветовые теги: промо, лайфстайл, продукт, обучение, развлечение, бэкстейдж
- **Общие заметки** — идеи и напоминания без привязки к дате
- **Drag & drop** — перетаскивание между днями в календаре и изменение порядка внутри дня
- **Копирование** — дублирование записей на другую дату
- **Сторис** — закрепление и привязка к хайлайтам
- **Тёмная тема** — переключение светлой/тёмной темы
- **Счётчик символов** — лимит 2200 для постов и каруселей
- **Общая ссылка** — делись планом через URL (данные кодируются в hash)
- **Анимации** — плавные переходы при открытии/закрытии панелей, смене дня, появлении карточек

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build    # TypeScript проверка + Vite production build
npm run preview  # предпросмотр production-сборки
npm run lint     # ESLint
```

## Стек

- React 19 + TypeScript 6 + Vite 8
- Redux Toolkit (Immer) для управления состоянием
- SCSS Modules для стилей компонентов
- Без роутера, без бэкенда — всё работает в браузере
- Данные сохраняются в `localStorage`
